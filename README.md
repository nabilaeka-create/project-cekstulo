# CekStulo

Web app untuk mengecek dan memantau keramaian Student Lounge (Stulo)
Fasilkom UI secara real-time.

## Latar Belakang
Jeda kuliah 1-2 jam membuat banyak mahasiswa menunggu di Stulo (lantai 5
dan lantai 1), yang sering penuh. Mahasiswa tidak punya cara untuk tahu
kondisi Stulo sebelum tiba di lokasi.

## Solusi
Aplikasi web berbasis Python yang menampilkan status keramaian tiap
lantai (sepi, sedang, ramai) melalui check-in dengan QR code serta
check-out manual dan otomatis.

## Tech Stack
Python, Flask, SQLite, HTML/CSS/JavaScript
